# ADR-0001 独立重建与云端基础优先

用户于2026-11-06明确要求在新目录完整重建，旧 swim 与技术页重做仅供模块/设计参考；随后选择首个可运行版本优先账号、机构与场馆，并指定新 GitHub 仓库。

已确认的范围：新版 `swim-platform/` 为正式开发入口；独立 Git 历史与配置；不把旧原型修补作为默认路线；历史资料分类归档并保留兼容路径；工期仅作参考。

当前实现采用 FastAPI/SQLAlchemy、可撤销 opaque session、UUID 标识、TenantMembership 与 SiteMembership。SQLite 仅作为可立即验证的本地开发条件。上述实现是可评审基线，不等于云端生产数据库、RLS、身份联合与公网部署已批准。

旧审计中的媒体、回写身份、任务恢复、模型 stub 问题转为新版设计与验收输入，不再默认修改旧仓库。旧审计结论和历史实验记录保留原貌。
